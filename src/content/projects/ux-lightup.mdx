## The idea

Filtering is where most furnishing storefronts quietly give up. Price, rating,
maybe a category — which is fine for a commodity and useless for a fixture that
has to match three others already in the room.

So the filter panel is the screen that got the attention: type, finish, cost
range, material, design and rating, with finish presented as swatches rather
than as a word list. A brushed-brass filter is a real constraint; a four-star
filter is not.

The order-status screen is a timeline — placed, processing, delivery, delivered
— because the question after buying a chandelier is never *what did I order*, it
is *where is it*.
